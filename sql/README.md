# SQL Analytics Layer

This folder adds an interview-ready SQL analytics and data-quality layer to the Cloud Job Market Intelligence project.

Covered concepts:
- JOINs
- Aggregations
- GROUP BY / HAVING
- CTEs
- Window functions (RANK)
- CASE statements
- Data-quality validation
- Referential-integrity checks
- Reconciliation
- Date-based analytics

## Files

- `analytics_queries.sql` — business analytics
- `data_quality.sql` — validation and reconciliation

## Interview line

"I modeled the warehouse as a star schema and use SQL joins to combine the fact table with dimensions. I use CTEs for reusable logic, window functions for ranking, CASE expressions for segmentation, and separate validation/reconciliation queries for data quality."
